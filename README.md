# Sahithisri Cheruku — Portfolio

Phase 1 of a cinematic software engineering portfolio built with Next.js App Router, React, TypeScript, Tailwind CSS, and semantic HTML.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run lint` and `npm run build` for validation.

Animation packages (GSAP, `@gsap/react`, and Lenis) are installed for a later phase; complex animation is intentionally not implemented yet.
